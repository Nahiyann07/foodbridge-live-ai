# FoodBridge Live

**Predict surplus. Track it live. Recover food before it becomes waste.**

FoodBridge Live is a full-stack Next.js application created by **NAHIYAN S**.

It coordinates a time-sensitive food-recovery journey from a canteen to verified community partners. The application predicts likely surplus, maintains a live inventory ledger, ranks recipients, prevents double claiming, coordinates pickup, verifies handover, and tracks impact.

## Quick Start

```bash
npm install
npm run dev
```

## Features

- **Authentication:** Secure login and registration powered by Supabase.
- **Provider Dashboard:** Create and track food batches, and open recovery opportunities.
- **NGO Matching:** Transparent ranking based on distance, capacity, and readiness.
- **Live Pickup:** Real-time collection tracking and verification.
- **Impact Analytics:** Dashboard for reporting and measuring recovered food.
